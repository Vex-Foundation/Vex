# Wave 2 doctrine migration ledger

## Scope and interpretation

This ledger is the deletion gate for build turn 2. A sentence may be removed from the old protocol layer only when its row below names either the injected tool description that already carries it or exactly one surviving prompt destination.

Repository evidence corrects the plan's count: `buildProtocolsPrompt` contains seven hand-written doctrine headings after the generated Chain Coverage section, not six. They are Swap Venue Routing, Trench Launch, pools.fun Launchpad, Virtuals Agent Tokens, Fixed Yield (Pendle), Lending (Morpho), and Bridge Routing. This ledger covers all seven, the generated Chain Coverage prose, and every rendered capsule field (`summary`, `whenToUse`, and `preferInstead`) for all eleven namespaces.

Verdicts:

- `DUPLICATED`: deletion is allowed only because the row names an injected tool description and its carrying phrase.
- `JUDGMENT`: the sentence or semantic clause survives exactly once in the named declaration, task shape, turn projection, or preserved prompt destination.
- `PRESERVE EXACT`: approval, authority, money-path, or irreversible-effect wording remains byte-identical at the named destination. It is not paraphrased into a declaration.

Existing em dash characters in quoted source are written as `\\u2014`; the authored artifact contains no em dash character.
