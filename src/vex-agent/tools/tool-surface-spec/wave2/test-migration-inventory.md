# Wave 2 prompt test migration inventory

## Scope and stop rule

This inventory covers every prompt-text assertion in the 26 pre-wave files measured by `recon.md` section 5: the 25 test files under `src/__tests__/vex-agent/engine/prompts/` that existed at revision `4ef0cfda`, plus `src/__tests__/vex-agent/engine/runtime-clock.test.ts`. It also includes the new WP0 `promptsnaps.test.ts` assertion that section 5 could not have counted.

One row represents one source assertion using `toContain`, `toMatch`, or string-valued `toBe`. The non-content type check `expect(typeof section).toBe("string")` is excluded. This reproduces 773 pre-wave prompt-text rows and adds one WP0 row, for 774 rows total. Existing em dash characters are recorded as the escape `\\u2014` so this artifact introduces no em dash character.

The category is about whether the assertion source may be edited in build turn 2:

- `invariant`: the assertion and its protected contract must not change. Any required edit is a stop.
- `wording`: the old location or wording is intentionally replaced. The row states the new contract and destination that must replace it.

The inventory is deliberately assertion-granular. A test may contain both invariant and wording rows.
