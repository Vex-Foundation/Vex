# Open owner decisions on the agent tool surface

A register of decisions that are OPEN, do not block current work, and have a
stated default that is in force until the owner rules otherwise. Written so
the program can be resumed from a cold start. Evidence paths are relative to
the repository root. Closed decisions live in
`tool-surface-spec/owner-decisions.md` (D1 to D13); this file only holds what
is still open.

Rule for every entry: tool BEHAVIOR is frozen (handler logic, parameter
semantics, approvals, persisted writes). An entry marked BEHAVIOR changes
what a tool does and needs an explicit owner ruling before any edit; an
entry marked METADATA changes names, descriptions, schemas, projection or
prompt text only.

## How to use this file

- An entry leaves this file when the owner rules: the ruling moves to
  `tool-surface-spec/owner-decisions.md` as the next D-number and the row is
  deleted here.
- A new open item is added here the moment it is found, with its default
  and its class, so that an interrupted session never loses a pending
  question.
- Nothing in this file authorizes an edit. Defaults are what the code does
  today.
